# INEC_NG-Report
This repository contains a report of the 2023 Presidential election held in Nigeria.

### Project Title: 2023 Presidential Election

### Project Overview
#### This Project aims to generate insights from the 2023 Presidential Election Datasets. It shows how each geo-political zone voted, the total population of registered voters in the country and which party was able to pull up the highest votes and so on. By analysing the parameters in the data received I gather insights to make reasonable decisions which helps to create an interactive dashboard to tell compelling stories and get the performance for each party across the country in different states.

### Data Source
#### The primary source of data used was provided by Data Science Nigeria (DSN) x Microsoft.
